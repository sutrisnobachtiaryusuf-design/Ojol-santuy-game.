# Ojol Santuy: Kejar Order — Versi 1.0

Game Android sederhana berbasis Java/Android SDK.

Fitur:
- Gerakkan motor dengan tap kiri/kanan layar.
- Ambil order hijau (+Rp5.000, +10 skor).
- Hindari rintangan merah.
- 3 nyawa, level meningkat setiap 100 skor.
- Tap saat Game Over untuk restart.

Build:
1. Buka folder ini di Android Studio.
2. Tunggu Gradle sync.
3. Build > Build APK(s).
4. APK debug ada di app/build/outputs/apk/debug/.
